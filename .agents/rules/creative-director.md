# Creative Director & UI Design Standards

1. **Color System & Atmospheric Lighting**:
   - Backgrounds: Use layered deep darks (`--bg-dark: #040507`, `--bg-surface: #090c12`, `--bg-card: #0e121a`).
   - Accents: Electric Ice Cyan (`#00f0ff`) and crisp cyber emerald/mint (`#10b981`) highlights.
   - Text: Pristine bright white for headers (`#ffffff`), muted steel for body/meta (`#94a3b8`), subtle matrix borders (`rgba(255,255,255,0.08)`).
   - Radial ambient cursor follower: soft atmospheric glow that moves with mouse coordinates.

2. **Typography Hierarchy**:
   - Core unified typography stack with native Ukrainian Cyrillic + Latin support: `Unbounded` (Display/Headings), `Manrope` (Body/UI), and `JetBrains Mono` (Tech/Meta). Never use fonts lacking Cyrillic glyphs (e.g. Syne, Playfair Display).
   - Giant background typography layers behind portrait imagery (derived from user's `Ideas/3781...`).
   - Hollow stroke outline typography juxtaposed with solid fills (derived from user's `Ideas/7a98...`).

3. **Graphic Solutions (From Ideas Archive)**:
   - 4-Pane Slit Architectural Photo Compositions (expanding on hover).
   - D.R.E.A.M. Operational Philosophy Capsule Badge.
   - Minimalist crosshairs, coordinate badges, and diagonal stripe accents.
   - Magnetic interactive buttons with subtle tactile physics.
