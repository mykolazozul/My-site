## Universal Agent Operating Protocols

### A. Constructive Critique & Objective Analysis (Ні сліпому схваленню)
All agents MUST NOT simply say "yes" or offer blind flattery to user ideas. Agents operate as high-caliber executive co-founders and strategic partners:
- For every proposed idea, layout, feature, or design change, agents provide a structured assessment:
  1. **Плюси (Strengths & Value)**: What genuinely works well, why it makes sense.
  2. **Мінуси та підводні камені (Cons, Risks & Hidden Costs)**: Impact on conversion funnels, cognitive load, mobile touch usability, SEO dilution, rendering overhead, or narrative conflict.
  3. **Нові пропозиції / Покращені апгрейди (Better Alternatives & Upgrades)**: Proactively present stronger, more elegant, or higher-converting iterations that achieve the user's underlying ambition at an even higher standard.

### B. Multilingual Font & Character Set Integrity Rule (Перевірка підтримки мов)
- **Mandatory Pre-flight Font Audit**: Before introducing or applying any font to the project, agents MUST verify that the font natively supports all target languages (specifically **Ukrainian Cyrillic**: `і`, `ї`, `є`, `ґ`, as well as Latin and international subsets).
- Never allow a font without Ukrainian Cyrillic glyphs to be set on headings or body copy (e.g. Playfair Display or Syne which lack Cyrillic), as it triggers fallback to generic system fonts (Times New Roman / Arial / Segoe UI) and damages the executive aesthetic.

### C. Self-Hosted Fonts & Zero Font Bloat Rule (Локальні шрифти та захист від перевантаження)
- **Mandatory Local Self-Hosting**: All web fonts MUST be self-hosted locally in `assets/fonts/` as modern, compressed `.woff2` files and linked via `assets/css/fonts.css` with `font-display: swap;`.
- **Strict Prohibition of External Font CDN Requests**: Never add external `<link href="https://fonts.googleapis.com/...">` or CSS `@import url("https://fonts.googleapis.com/...")`. Self-hosting eliminates render-blocking network latency, removes DNS lookups and TLS handshakes, and guarantees 100% offline resilience and privacy.
- **Unified 3-Font Stack Core (Zero Bloat)**: The portfolio strictly relies on a curated 3-font core to prevent visual chaos, excessive payload, and font clash:
  1. `Unbounded` (`--font-display`): Expressive brutalist geometry for display titles & key headings. Supports Ukrainian Cyrillic (`і`, `ї`, `є`, `ґ`) + Latin.
  2. `Manrope` (`--font-sans` / `--font-body`): Clean, highly readable neo-grotesque for UI, navigation, cards, and body copy. Supports Ukrainian Cyrillic + Latin.
  3. `JetBrains Mono` (`--font-mono`): Technical monospaced precision for badges, timestamps, metrics, code, and metadata. Supports Ukrainian Cyrillic + Latin.
- **Weight Pruning & Prohibition of Secondary Bloat**: Only download and serve the exact weights needed (Unbounded: 600..900; Manrope: 400..800; JetBrains Mono: 400..700). Prohibit adding one-off decorative fonts that increase page weight or break typography harmony.
